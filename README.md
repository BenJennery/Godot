<p style="color: #cccc99;">
  Making a video game with the following scenery, I have learned a lot about the process I want to achieve so aim to rewrite the code in a simpler way. The main method is generating a grid of hexagons with a given height given by a partially random function then iterating over the grid to change the heights depending on different rules designed to create pleasant geometry (dont like saddle points) and make every hexagon accessible(to an extent). The next step is to then create a new grid of vertices and set the vertex position to the height of the hexagonal cell. using the vertex grid, triangles are formed as shown in the video below.
